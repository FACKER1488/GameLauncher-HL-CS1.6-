# Game Launcher

A multi-launcher I built for Half-Life and CS 1.6. One EXE — downloads from Google Drive, unpacks, launches. No admin rights, no WinRAR.

## Features

- Single `.exe` (~10 MB), both games inside
- Downloads from Google Drive — no account, no signup
- Unpacks with built-in `zipfile` — no extra software needed
- Separate theme per game: HEV-suit for HL, gold for CS
- Auto-creates desktop shortcuts — one per game
- `sv_cheats` toggle for CS 1.6
- No admin rights needed

## How to use

1. Grab `Game Launcher.exe` from [Releases](../../releases)
2. Run it. If SmartScreen shows up — click **"More info"** → **"Run anyway"**
3. Pick a game at the top (H or C)
4. Click DOWNLOAD and wait
5. It unpacks the game and offers to launch it

⚠️ **Important:** keep the EXE somewhere writable:
- ✅ `C:\Games\`, Desktop, `D:\`, USB stick
- ❌ `C:\Program Files\`, `C:\Windows\`
